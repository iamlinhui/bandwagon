基于 KiwiVM Basic Shell:每条命令都是一次独立执行(非 PTY),不支持 top/vim 等交互程序, 环境变量与后台任务不会保留;cd 由看板代为记忆。

SSH 终端
— 未连接
真 PTY:top / vim / tab 补全 / 颜色 / 后台任务 / 环境变量都正常,窗口大小会自动同步; 账号密码只存在服务器端,浏览器只传按键与画面。首次连接请核对主机密钥指纹,点「固定指纹」复制配置片段写进 instances[].ssh.host_key_fingerprint 即可防中间人。
